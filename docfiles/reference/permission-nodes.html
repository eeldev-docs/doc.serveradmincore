Permission Nodes

All built-in nodes. In C++ they are available as constants in the ServerAdminCorePermissions namespace (ServerAdminCorePermissions::Kick, …).

Matching rules​

  • * matches everything.
  • prefix.* matches prefix and everything below it: serveradmincore.ban.* matches serveradmincore.ban.ip.
  • Matching is case insensitive.
  • A node starting with - denies. If any denial in the player's effective permissions matches, the permission is denied, even if another node grants it.
  • Effective permissions = the group's permissions plus all inherited groups' permissions.
