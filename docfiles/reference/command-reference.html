Command Reference

<required> and [optional] arguments. Commands and aliases are case insensitive. In chat, prefix commands with the Command Prefix (default /). In the dedicated server console window, type them without a prefix. In the editor console, prefix them with sac or ServerAdminCore.

See Targeting players for what <player> accepts, and Durations for <duration>.
