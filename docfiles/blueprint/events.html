Events

Server events (Server Admin Core subsystem)​

Bind these on Get Server Admin Core, on the server.

EventParametersWhen
On Player JoinedPlayer InfoA player joined (after ban and whitelist checks)
On Player LeftPlayer InfoA player left
On Player KickedPlayer Id, Player Name, Reason, Caller
On Player BannedSanction, CallerBan or temp ban
On Player UnbannedPlayer Id, CallerManual or expired
On Player MutedSanction, Caller
On Player UnmutedPlayer Id, CallerManual or expired
On Player Group ChangedPlayer Id, New Group
On Whitelist ChangedEnabled
On AnnouncementMessage, TypeEvery announcement, including countdown warnings
On Chat MessageSender, MessageChat sent through Server Admin Core, after the mute check
On Command ExecutedCaller, Command Line, Result
On Pending Action ChangedActionMap change, restart or shutdown scheduled, cancelled or executed
On Admin LogEntryEvery admin log entry
On Auto Kick WarningPlayer Id, Player Name, Reason, Seconds LeftA player will be kicked for being AFK or for high ping. See AFK and High Ping Kick
On Local Player KickedReasonClient side. The local player is being kicked. Fires just before the disconnect. See Showing the kick reason to the player
tip

Bind the events in your Game Mode or Game Instance. Since the subsystem lives on the game instance, bindings made on the game instance survive map changes.
