Blueprint

Blueprint Overview

Everything in Server Admin Core is available from Blueprint. There are three things to know about:

WhereUsed for
Server Admin Core subsystemServerAll admin functions and server events
ServerAdminCore Player ComponentOn every player controllerClient side: chat, commands, announcements, admin panel
Server Admin Core Blueprint LibraryAnywhereHelpers: player ids, durations, permissions

Getting the subsystem​

Use Get Server Admin Core from any Blueprint that has a world context (actors, components, widgets, game mode…).

warning

Admin functions only work on the server. On a client, Is Server Admin Core Active returns false and admin functions return Not Server. Clients talk to the server through the Player Component.

Callers​

Every admin function takes a Caller (FServerAdminCoreCaller):

  • Make Caller (Player Controller): the action is done by that player. Permissions and group priority are checked.
  • Make System Caller (Name): the action is done by the game. No checks. The name shows up in the admin log.
Event OnCheatDetected (PlayerController)
 └─ Get Server Admin Core
     └─ Ban Player
          Caller:              Make System Caller ("AntiCheat")
          Player Id:           Get Player Id (PlayerController)
          Reason:              "Cheat detected"
          Duration Seconds:    2592000   (30 days)
          Ban IP Address:      true

Results​

Admin functions return EServerAdminCoreResult:

ResultMeaning
SuccessDone
No PermissionThe caller lacks the permission
Player Not FoundThe target is not online / not known
Target ImmuneThe target has an equal or higher priority, or is the caller
Already ExistsE.g. already whitelisted
Not FoundE.g. no ban to remove
Invalid ArgumentsE.g. empty name
MutedThe sender of a chat message is muted
Not ServerCalled on a client, or Server Admin Core is disabled
FailedSomething else went wrong

Use Result To String to get a readable message.
