Getting Started

Installing the plugin

Install from Fab​

  1. Open the Epic Games Launcher and go to Unreal Engine → Library → Fab Library.
  2. Search for Server Admin Core.
  3. Click Install to Engine and select your engine version (5.5, 5.6, 5.7 or 5.8).

Enable the plugin​

Open your project, go to Edit → Plugins, search for Server Admin Core and make sure it is enabled. Restart the editor when asked.

note

Server Admin Core is a code plugin. A Blueprint only project works fine, but you need a C++ project (or a source build of the engine) to package a dedicated server, since Unreal Engine does not ship prebuilt server targets. Listen servers work in any project.

Installing manually (project plugin)​

You can also place the plugin in your project instead of the engine:

YourProject/
└── Plugins/
    └── ServerAdminCore/
        ├── ServerAdminCore.uplugin
        ├── Config/
        ├── Resources/
        └── Source/

Right click your .uproject → Generate Visual Studio project files, then build your project.

Verify the installation​

Start your project in Play as Listen Server and type in the console:

sac status

You should see the current map and the number of players online. If you see ServerAdminCore: no active server world found., you are running as a client or standalone. See Testing in the Editor.
