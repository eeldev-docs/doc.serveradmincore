Remote Control

Remote Settings

Project Settings → Plugins → Server Admin Core Remote, stored in Config/DefaultGame.ini under [/Script/ServerAdminCoreRemote.ServerAdminCoreRemoteSettings].

RCON​

SettingConfig keyDefaultDescription
Rcon EnabledbRconEnabledfalseStarts the RCON listener on dedicated servers. The password is never read from config.
Rcon PortRconPort27020TCP port.
Rcon Bind AddressRconBindAddress127.0.0.1RCON sends the password unencrypted, so only change this behind a VPN or firewall.
Rcon Group NameRconGroupNameOwnerPermission group that RCON commands run as.
Rcon Max ConnectionsRconMaxConnections4Simultaneous connections.
Rcon Max Failed LoginsRconMaxFailedLogins5Failed logins from one IP before it is blocked.
Rcon Block SecondsRconBlockSeconds900How long an IP stays blocked.
Rcon Allowed IpsRconAllowedIps–If not empty, only these IP addresses may connect.

REST API​

SettingConfig keyDefaultDescription
Api EnabledbApiEnabledfalseStarts the REST API on dedicated servers.
Api PortApiPort27021TCP port.
Api Bind AddressApiBindAddress127.0.0.1The engine HTTP server has no TLS. Use a reverse proxy for remote access.

WebSocket​

SettingConfig keyDefaultDescription
Web Socket EnabledbWebSocketEnabledtrueStarts the event stream. Needs the REST API to be enabled.
Web Socket PortWebSocketPort27022TCP port.
Web Socket Bind AddressWebSocketBindAddress127.0.0.1No TLS. Use a reverse proxy for remote access.
Web Socket Max ConnectionsWebSocketMaxConnections8Simultaneous connections.

Command line​

ArgumentDescription
-RconPassword=...RCON password. The environment variable SERVERADMINCORE_RCON_PASSWORD works too.
-ServerAdminCoreManagedManaged mode, set by the watchdog.
-ServerAdminCoreRestartFlag=<file>Restart flag file, set by the watchdog.
