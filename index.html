Server Admin Core

Server admin for Unreal Engine dedicated servers and listen servers.

Server Admin Core is an admin and moderation toolkit for Unreal Engine multiplayer games, on dedicated servers and listen servers. Drop it into your project, start your server and you get everything players and server owners expect: kick, ban, mute, whitelist, admins and moderators, server commands, announcements, map changes, restarts and shutdowns, player info, player notes and admin logs.

Everything is available from Blueprint and C++.

tip

New to the plugin? Start with Installing the plugin and the Quick Start. You can be kicking and banning in PIE within five minutes.

Features​

FeatureDescription
KickKick players with a reason.
AFK and High Ping KickKick idle players and players with too high ping, with warnings and staff exemptions.
Ban / Temp Ban / UnbanPermanent, timed and IP bans. Works for offline players. Enforced at login.
Mute / Temp Mute / UnmuteBlocks text chat and voice chat. Expires automatically.
WhitelistToggle at runtime, add players before they ever join.
Admins, Moderators and Permission GroupsGroups with priority, inheritance, wildcards and denials.
Server Commands38 built-in commands from chat, the server console or Blueprint. Add your own.
Server AnnouncementsInstant, scheduled and welcome messages.
Change Map, Restart, ShutdownCountdowns with warnings, cancel at any time.
Player List and Player InfoPlay time, known names, ping, IP, ban and mute state.
Player NotesPrivate staff notes per player.
Admin LogsEvery action logged to memory, the output log and daily files.
Blueprint + C++Full API, events, an in-game admin panel bridge and pluggable storage.
