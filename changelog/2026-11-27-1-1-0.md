## **GENERAL**

- New module **ServerAdminCoreRemote** for [remote control](/docfiles/remote/overview) of dedicated servers
- IP addresses are removed from all REST and WebSocket output unless the token's group has `serveradmincore.info.ip`
- Free [companion tools](/docfiles/remote/companion-tools): watchdog, Discord bot and web panel, downloaded separately

## **ADDED**

- Source **RCON** listener, compatible with mcrcon and other Source RCON clients
- **REST API** with health, status, players, bans, logs and command endpoints
- **WebSocket event stream** with token authentication and per-connection permissions
- **API tokens** with the `token create`, `token list` and `token revoke` commands
- **Managed mode** for restarts under the watchdog, with a restart flag file
- Remote caller and thread-safe command queue, so remote commands run on the game thread with the caller's group permissions
- **Require Verified Ids** setting and **Mark Player Id Verified** function, so owner ids only count after your game has authenticated the player
- **Rpc Burst**, **Rpc Refill Per Second**, **Max List Rpc Items** and **Players Save Interval Seconds** settings

## **FIXED**

- Temporary `Session_N` ids are rejected for ban, whitelist and setgroup
- Sanction duration is capped
- Data that failed to load is no longer overwritten on save
- The hosting player on a listen server is never rejected by the player checks
- Admin client requests are rate limited and large lists are capped, so a client can no longer flood the server
- `Players.json` is saved at most every 30 seconds by default, which avoids hitches on servers with many known players
- Creating a token for your own group works, and refusals explain why
